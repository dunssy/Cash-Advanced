# Audit Favicon Login

Audit statis pada deklarasi favicon di halaman login. Tidak ada perubahan pada template maupun aset lokal.

## Temuan

### 1. MEDIUM: PNG favicon dinyatakan sebagai ICO

**Lokasi:** [resources/views/auth/login.blade.php](../resources/views/auth/login.blade.php#L10)

Kedua sumber bertema memakai file PNG (`favicon.png` dan `favicon-dark.png`) tetapi deklarasi `type` menyebut `image/x-icon`. Browser dapat mengabaikan tipe sumber tersebut atau memilih ikon fallback, yang berpotensi membuat favicon terlihat berbeda dari mark navy yang disediakan untuk tema terang. Tidak ditemukan CSS yang membalik atau menggelapkan warna ikon.

**Usulan:** deklarasikan sumber PNG sebagai `image/png`, pertahankan `media="(prefers-color-scheme: dark)"` untuk mark putih, lalu periksa hasilnya di light dan dark mode. Layout aplikasi sudah memakai `.ico` dengan tipe `image/x-icon`, jadi temuan ini terbatas pada halaman login.

**Batas audit:** kode dan metadata aset diperiksa secara statis; browser belum diuji. Cache favicon browser dapat membuat perubahan terlihat terlambat setelah perbaikan.
